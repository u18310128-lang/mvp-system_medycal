    Qué ocurre al registrar

    1. La cita se guarda en estado PROGRAMADA.
    2. El sistema programa la secuencia de recordatorios en T-48 h, T-24 h y T-3 h.
    3. Los hitos ya vencidos se omiten: si la cita es para mañana, no se envía el de 48 horas.
    4. El motor rechaza el horario si el médico ya lo tiene ocupado.
